# SAF-026 evaluation protocol

Run from app root: `PYTHONPATH=apps/api uv run --offline python -m safer.evaluation --security`. Reports and JUnit evidence go to `.local/evaluation/saf026` with private file permissions. Without `--security`, the regression gate is incomplete and exit status is nonzero. Required test identities are independently collected with inherited pytest selection/plugins disabled; missing, duplicate, skipped or failed executions cannot pass. JUnit and the collection manifest must agree exactly. CI includes this step and uploads only synthetic artifacts; hosted execution is not claimed.

The corpus contains 138 synthetic documents across six additional layout families, multiple pages, label damage, conflicting values, leading-zero/altered references, impossible dates, scanned/noisy/multilingual images, instruction-like text and amount edge cases; 12 review cases cover low/high exact decimal amounts, matching/mismatching/simulated/unconfirmed evidence and closed cases. No real or anonymized institutional records are used. Any such data requires written approval from AICTE's data owner first.

Documents are generated reproducibly into real PDFs/PNGs. PDF inputs use the actual isolated text parser; extraction proposals use production rules. Raster inputs are explicitly manual-only because OCR is not configured; their answerable fields remain in the denominator and score zero extracted coverage. This does not evaluate OCR or multilingual recognition. The comparison and summary runner uses actual application functions on synthetic read models; API security regressions separately cover scope/revocation, instruction-like data, immutable provenance and no authoritative side effects.

Metrics: exact-match = correct proposals / answerable fields; selective accuracy = correct / proposed; critical errors = wrong proposed values including proposals where labels require abstention; abstention = abstained / all field opportunities. Zero denominators are N/A, not 100%. Per-field and per-stratum counts, parser failures, comparison precision/recall, summary fact equality and section-specific source/version resolution are reported. Raw document content is excluded from reports. Latencies use nearest-rank local p50/p95 and exclude queue wait/network transfer; human corrections/time and infrastructure cost are unmeasured. External inference calls and fees are zero for this provider-free mode.

Initial run with text-rules-1: **2 unsafe proposals** (truncated overprecision, out-of-range principal). Fix text-rules-2 abstains on invalid precision/grouping/range. The observed corpus is now explicitly **synthetic regression** data. Do not describe the corrected results as independent held-out generalization. A fresh, representative held-out corpus and owner-approved thresholds remain required before pilot.

The gate requires zero critical wrong proposals, zero parser failures, zero summary/citation errors, no comparison false positives/negatives and a passing executed API security suite. It always leaves the real-data pilot blocked. These are local regression assertions, not owner-approved production accuracy thresholds or human utility evidence. Re-run whenever parser, comparison, summary templates, dependencies or dataset changes; source hashes, library versions, input hashes and corpus hash are recorded.

See [measured results](SAF-026-RESULTS.md). No cloud API, model, external data transfer or real-data approval is involved.
