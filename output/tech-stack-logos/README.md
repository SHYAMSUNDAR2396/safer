# SAFER technology logos

Separate logo files downloaded from official project sites and the Devicon collection. Original assets are in `01-main-stack/` and `02-supporting-tools/`. PPT-friendly PNG copies are in `PNG/`. The main-stack preview identifies the 11 recommended PPT sidebar logos.

SVGs remain vector. PNGs preserve aspect ratios and source backgrounds, with a maximum dimension of 1200px. Some source PNGs may have been enlarged for a consistent import size; the SVG originals provide vector quality where available. No logo artwork was generated or redesigned.
