# SAFER OCI production architecture package

The main PNG clearly places SAFER inside an OCI tenancy, Mumbai region, VCN and public/private subnet boundaries, with Hyderabad recovery. It is a proposed paid production target, not evidence of a deployed or certified environment.

Read SAFER-OCI-PRODUCTION-ARCHITECTURE.md for decisions, service inventory, request flow, network policy, capacity assumptions, recovery objectives, implementation phases, cost controls and launch gates. Region choices and the ₹75,000/month pre-tax planning ceiling were selected by the architect after the user delegated those decisions. The budget is not a provider estimate.

Open the .excalidraw file using Excalidraw's Open command. Text, shapes, arrows and embedded images remain individually editable. The SVG also embeds its artwork. The PNG is 7200 × 4960 pixels; the smaller preview is for convenient viewing.

Artwork: official OCI diagram toolkit service symbols plus the existing attributed SAFER technology logo collection. See the main proposal's artwork section and included provenance files. OCI Cache uses a generic database symbol explicitly labelled with its service name.

Local validation found no missing embedded assets, invalid geometry or text-width overflow. This validates the diagram file, not the software's production readiness. No cloud account was accessed and no cloud resources or real data were activated.
