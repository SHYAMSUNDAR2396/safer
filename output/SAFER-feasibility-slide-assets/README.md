# SAFER feasibility / viability slide assets

35 generic pictograms plus 3 official UN SDG graphics. Files are separate and can be inserted individually into PowerPoint or Canva.

- `SVG/`: original Lucide vector icons, scalable and recolorable.
- `PNG-black/`: transparent 768×768 black icon copies.
- `PNG-colored/`: transparent 768×768 icon copies using the slide section colors.
- `07-SDG/`: unchanged official source images for SDG 9, 12 and 16.
- `PNG-SDG/`: PNG copies of the same SDG graphics.
- `slide-main-assets-preview.png`: recommended symbols for the visible slide sections.
- `all-assets-preview.png`: every asset, including the 16 impact/effort feature points.

## Recommended placement

| Slide section | Asset folder |
|---|---|
| Economic / social / environmental benefits | 01-benefits |
| AICTE / institutions / reviewers / approvers / banks | 02-stakeholders |
| Four impact/effort quadrants | 03-impact-effort |
| Technical / economic / operational / pilot-adoption strip | 04-feasibility |
| Our promise and before/after comparison | 05-promise-comparison |
| Individual points inside the matrix | 06-feature-symbols |
| SDG alignment | 07-SDG |

The AICTE/regulator symbol is a generic shield icon, not an official AICTE logo. Other stakeholder icons likewise represent roles, not organizational endorsements. MoSPI, PRAGATI, PM Gati Shakti and NITI Aayog logos from the earlier template are not included because they do not represent established SAFER integrations.

## Sources

Lucide library: https://lucide.dev/icons ; license: https://lucide.dev/license . The distributed license is included in LUCIDE-LICENSE.txt. Colored PNG variants change only the configurable icon stroke color.

UN communications materials and usage guidance: https://www.un.org/sustainabledevelopment/news/communications-material/ . The SDG files were downloaded directly from sdgs.un.org. Keep their original colors, proportions and wording. For published slides, include the non-endorsement notice required by the UN communications guidelines. The assets do not establish UN endorsement or verified SDG impact.
